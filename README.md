# Islet

A Dynamic Island for macOS. A small glass pill floats at the top of the screen, under the menu bar. Hover it and it opens into a card with the current track, synced lyrics, the clock, battery, and a file shelf; move the cursor away and it folds back to a pill.

Runs on Electron, so it is a normal `.app` with its own bundle id, native vibrancy behind the glass, and no Dock icon.

## What it does

- **Now playing** — track, artist, album art, and a scrubber, read from Music or Spotify.
- **Synced lyrics** — time-aligned lyrics that follow playback position; falls back to plain lyrics when only those exist.
- **Idle card** — date, time, and battery while nothing is playing.
- **File shelf** — drop a file on the island, drag it back out later or reveal it in Finder.
- **Click-through** — only the card itself takes clicks; anywhere else, clicks go to whatever is behind it.

## Requirements

- **macOS.** Built and tested on macOS 26.7.3 (Apple silicon). The window is pinned under the menu bar, so the island sits below the notch rather than inside it.
- **[Bun](https://bun.sh)** to install dependencies and run the scripts. `sqlite`-free and dependency-light otherwise.
- **Music or Spotify** for anything playback-related. Either one is enough; the app uses whichever is running.
- **Automation permission** for Islet (see below). Without it the island still shows the clock, battery, and shelf — just no track.
- **An internet connection** for lyrics. They come from [LRCLIB](https://lrclib.net), queried by title, artist, album, and duration, and cached in memory per track.

## Run it

```bash
bun install
bun start
```

`bun start` launches Electron directly from `node_modules` rather than through the `electron` bin shim, which needs Node on `PATH`. Islet opens as a narrow pill at the top of the primary display with no Dock icon; hover to expand it.

## Build the `.app`

```bash
./tools/build-app.sh
```

This copies the Electron runtime out of `node_modules` into `dist/Islet.app`, renames the executable, writes an `Info.plist` (display name, `pro.islet.app` bundle id, version from `package.json`, `NSAppleEventsUsageDescription`), embeds the app sources under `Contents/Resources/app`, then ad-hoc signs and verifies the bundle.

The result is `dist/Islet.app`, ready to launch or drag to `/Applications`. It is **ad-hoc signed**, not notarized — fine for your own machine, but a copy downloaded elsewhere may need Gatekeeper bypassed (right-click → Open, or `xattr -cr`). Override the bundle id with `BUNDLE_ID=… ./tools/build-app.sh` if you want to run two builds side by side.

`dist/` and `node_modules/` are gitignored; the repo carries source plus the build script, and the 250 MB runtime is regenerated by `bun install`.

## Automation permission

Islet reads playback state with AppleScript, so macOS asks for consent the first time it talks to Music (and again for Spotify):

> "Islet" wants to control "Music".

Choose **Allow**. Because the app is built as `Islet.app` with its own bundle id, the prompt names Islet rather than Electron, and **Privacy & Security → Automation** lists it as *Islet*.

If you clicked **Don't Allow**, the island silently shows no track. Fix it in **System Settings → Privacy & Security → Automation → Islet** and enable Music and/or Spotify. Rebuilding with a different bundle id counts as a new app and triggers a fresh prompt.

## Layout

```
main.js              window geometry, vibrancy, hover polling, IPC
preload.js           context-isolated bridge for the renderer
lib/media.js         AppleScript playback state and controls, artwork
lib/lyrics.js        LRCLIB lookup with in-memory cache
renderer/index.html  markup and CSP
renderer/styles.css  glass tokens, light theme, layout per island state
renderer/renderer.js render loop, lyrics sync, shelf, clock, battery
renderer/fonts/      Geist (Regular, Medium, SemiBold)
debug/capture.js     screenshot/geometry harness, only loaded with ISLET_DEBUG=1
tools/build-app.sh   packages and signs dist/Islet.app
```

The window is resized to exactly the card at all times: with native vibrancy, any extra window area would blur the desktop past the rounded glass. Hover is driven by polling the real cursor position in the main process instead of hit-testing inside a click-through window.
